# 支付相关

## 支持的支付方式

- 微信支付（零钱、银行卡）
- 支付宝（余额、花呗、银行卡）
- 银联云闪付
- 信用卡（Visa / MasterCard 境外卡需联系客服确认）
- 货到付款（仅限部分商品，运费另计）

## 分期付款

- **花呗分期**：支持 3/6/12 期，手续费率见商品页
- **信用卡分期**：支持 3/6/12 期，具体费率以发卡行为准
- 分期付款订单如需退款，手续费不退，请确认后再下单

## 退款到账时间

| 支付方式 | 到账时间 |
|---------|---------|
| 微信零钱 | 即时到账 |
| 微信银行卡 | 1-3 个工作日 |
| 支付宝余额 | 即时到账 |
| 支付宝银行卡 | 1-3 个工作日 |
| 银联云闪付 | 1-3 个工作日 |
| 信用卡 | 3-7 个工作日（以发卡行处理为准） |

## 支付安全

- 所有支付链路由微信/支付宝/银联直接处理，平台不存储用户银行卡信息。
- 建议开启支付密码和指纹/面容验证，防止误操作。
- 如发现异常扣款，请立即联系客服和对应的支付平台客服。

## 发票

- 支持电子发票和纸质发票，可在下单时选择。
- 电子发票在发货后 7 个工作日内发送至注册邮箱。
- 纸质发票随商品一同寄出。
- 企业发票需在订单备注中填写完整的开票信息和纳税人识别号。
