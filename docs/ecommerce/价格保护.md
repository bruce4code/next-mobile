# 价格保护

## 保价政策

- 在平台购买的商品，签收后 **7 天内** 如出现同一商品降价，可申请价格保护。
- 价格保护仅适用于平台自营商品，第三方商家商品以商家标注为准。
- 大促期间（618、双11、年货节等）的价格波动不纳入保价范围，活动规则另行说明。

## 申请条件

1. 申请时间：签收后 7 天内。
2. 同一商品：相同商品 ID、相同规格、相同颜色。
3. 差价计算：以申请时商品页面售价为准，不包含优惠券、满减、积分抵扣等叠加优惠。
4. 以下情况不支持保价：
   - 使用优惠券、满减活动购买的商品
   - 秒杀、限时特价、清仓活动商品
   - 拼团、直播间专享价商品
   - 赠品价值不计入差价计算

## 申请流程

1. App "我的"→"我的订单"→找到对应订单。
2. 点击"申请价格保护"（如未显示则该商品不支持保价）。
3. 系统自动核实当前售价和购买价，计算差价。
4. 审核通过后，差价以 **平台余额** 形式返还至您的账户。
5. 处理时效：提交后 1-3 个工作日。

## 常见问题

1. **保价成功后差价在哪里查看？**
   → 差价返还至平台余额，可在"我的"→"我的余额"中查看和使用。

2. **保价金额可以提现吗？**
   → 平台余额可用于下次购物抵扣，暂不支持提现。

3. **同一个商品买了多件，每件都能保价吗？**
   → 是的，每件商品单独计算差价。

4. **保价和退货重买哪个划算？**
   → 差价不大时建议走保价（省去退货物流时间），差价较大时退货重买可能更合适，请自行判断。
