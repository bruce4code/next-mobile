# 退换货政策

## 适用条件

1. **7天无理由退货**
   - 商品签收后7天内，不影响二次销售可申请
   - 需保持商品原状、吊牌未剪、包装完整
   - 运费由买家承担（退货运费约8-15元）
   - 生鲜食品、定制商品、内衣等不支持无理由退货

2. **质量问题退货**
   - 商品存在破损、功能故障、发错货等商家责任问题
   - 签收后15天内可申请
   - 运费由平台/商家承担，无需买家垫付
   - 请提供照片或视频作为凭证

3. **换货**
   - **质量问题换货**：签收后 **15 天**内可申请，运费由商家承担
   - **非质量问题换货**（尺码/颜色调换）：签收后 **7 天**内可申请，商品需保持完好
   - 换货默认发与原订单一致的快递，如需变更可联系客服备注

## 退货流程

1. 在订单页面点击「申请售后」
2. 选择退货或换货，填写退款原因
3. 上传凭证（照片、视频等）
4. 等待客服审核（通常1-3个工作日）
5. 审核通过后，系统推送退货地址
6. 寄回商品并填写物流单号
7. 商家签收确认后，退款到账

## 退款时效

| 支付方式 | 到账时间 |
|---------|---------|
| 微信零钱 | 即时到账 |
| 微信银行卡 | 1-3 个工作日 |
| 支付宝余额 | 即时到账 |
| 支付宝银行卡 | 1-3 个工作日 |
| 银联云闪付 | 1-3 个工作日 |
| 信用卡 | 3-7 个工作日（以发卡行处理为准） |
| 花呗 | 1-3 个工作日恢复额度 |

## 生鲜商品特别说明

- 收到后24小时内发现有腐烂、变质可申请退款
- 需提供坏果照片及快递面单
- 赔付标准：按坏果比例折算退款
  - 坏果 ≤ 30%：按比例退款
  - 坏果 > 30%：全额退款或补发
- 因个人保存不当导致的变质不属赔付范围

## 不可退货的特殊商品

- 食品/保健品：拆封后不支持退货
- 内衣裤袜：贴身衣物，拆封后不支持
- 定制/订做商品：按需生产，不支持退换
- 虚拟商品（充值卡、课程）：已发货不支持退
- 特价清仓商品：页面注明不退不换的

## 常见问题

1. **退货地址怎么获取？**
   → 客服审核通过后，退货地址自动显示在售后页面

2. **没有寄回单号怎么办？**
   → 使用任意快递寄回，在售后页面填写单号即可

3. **退款多久到账？**
   → 商家签收后24小时内处理，到账时间取决于支付方式，详见上方退款时效表

4. **换货发什么快递？**
   → 默认与原订单一致，如需变更可联系客服备注
